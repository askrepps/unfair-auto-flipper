# unfair-auto-flipper

After playing around a dozen runs of [Unfair Flips](https://store.steampowered.com/app/3925760/Unfair_Flips/)
this weekend without getting 10 heads in a row, I decided to put together a little simulator to play out multiple runs
and see how long it might take random people to do what I could not. (yet...)

Note: This simulation takes the game at face value and assumes it's telling the truth about its probabilities.

Also, beware the code and output will contain spoilers for the game. You should play it first. It's really cool.
